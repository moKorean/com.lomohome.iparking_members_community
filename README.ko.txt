아이파킹(iParking)을 사용하는 건물에 사는 분이, 자기 집에 오는 방문 차량의 주차를 아이파킹 MEMBERS를 통해 등록하는 앱입니다. 아이파킹 공식 앱이 아닌, 커뮤니티가 만든 비공식 앱입니다.

아이파킹 MEMBERS에 가입된 건물의 본인 세대 계정이 있어야 합니다. 계정 하나는 한 세대에 묶여 있어 그 세대에 오는 방문 차량만 등록할 수 있으니, 본인 계정으로 로그인해 본인에게 오는 차량만 등록하세요. 등록하면 단지의 실제 출입통제 시스템에 즉시 반영됩니다 — 시험 삼아 아무 번호나 넣지 마세요.

앱 설정에서 한 번 로그인하면 기기 화면에서 다섯 가지를 한눈에 봅니다. 오늘·내일·이번 주(오늘부터 7일) 방문 예정 대수, 지금 단지 안에 들어와 있는 차량 수, 그리고 다음 방문 예정일입니다. 다섯 개 모두 조회 한 건에서 나옵니다. 앱의 주 화면인 설정 페이지에서 주차장을 고르고 차량번호와 방문 예정일을 입력해 등록하세요 — 차량번호의 공백은 자동으로 정리됩니다. 같은 화면에서 지난 3개월과 앞으로 3개월의 등록 내역을 보고 취소할 수 있고, 플로우(Flow) 액션으로도 등록할 수 있습니다. 자주 오는 차량을 이름과 번호로 저장해 두면 한 번 눌러 등록하는 버튼이 생깁니다.

이미 등록된 차량을 다시 등록하면 오류가 아니라 별도의 결과로 안내하며, 등록 결과를 확인할 수 없을 때는 짐작하거나 다시 시도하지 않고 아이파킹 웹사이트에서 직접 확인하도록 안내합니다.

아이파킹이 공식 문서로 공개한 적 없는 API를 이용하는 비공식 클라이언트이므로, 벤더가 API를 바꾸면 예고 없이 동작을 멈출 수 있습니다. 아이파킹 API 서버는 안전하게 시작된 요청도 평문 연결로 되돌립니다. 그래서 로그인 이후의 접근 토큰과 차량번호 데이터는 암호화되지 않은 채로 오갑니다 — 이는 벤더 서버 쪽의 동작이며 이 앱에서 바꿀 수 없습니다. 로그인 자체는 검증된 보안 연결을 사용합니다. 계정 정보는 사용자 본인의 기기에만 저장되고 아이파킹 서버 외의 어디로도 전송되지 않으며, 이 앱은 분석·수집을 하지 않고 자체 서버도 두지 않습니다. "현재 주차 중"은 1시간마다 조회하므로 최대 1시간 늦게 반영됩니다.
