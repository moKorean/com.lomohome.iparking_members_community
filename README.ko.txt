아이파킹(iParking)을 사용하는 건물에 사는 분이, 자기 집에 오는 방문 차량의 주차를 아이파킹 MEMBERS를 통해 등록하는 앱입니다. 아이파킹 공식 앱이 아닌, 커뮤니티가 만든 비공식 앱입니다.

개인 용도 전용입니다. 아이파킹 MEMBERS에 가입된 건물의 본인 세대 계정이 있어야 하며, 계정 하나로는 그 세대에 오는 방문 차량만 등록할 수 있습니다. 본인 계정으로 로그인해 본인에게 오는 차량만 등록하세요.

앱 설정에서 한 번 로그인하면 오늘 등록된 차량이 몇 대인지 기기 센서로 확인할 수 있습니다. 앱의 주 화면인 설정 페이지에서 주차장을 고르고 차량번호와 방문 예정일을 입력해 방문 차량을 등록하세요 — 차량번호의 공백은 자동으로 정리됩니다. 같은 화면에서 등록 내역을 보고 취소할 수 있고, 플로우(Flow) 액션으로도 등록할 수 있습니다. 이미 등록된 차량을 다시 등록하면 오류가 아니라 별도의 결과로 안내하며, 등록 결과를 확인할 수 없을 때는 짐작하거나 다시 시도하지 않고 아이파킹 웹사이트에서 직접 확인하도록 안내합니다.

아이파킹 API 서버는 안전하게 시작된 요청도 평문 연결로 되돌립니다. 그래서 로그인 이후의 접근 토큰과 차량번호 데이터는 암호화되지 않은 채로 오갑니다 — 이는 벤더 서버 쪽의 동작이며 이 앱에서 바꿀 수 없습니다. 로그인 자체는 검증된 보안 연결을 사용합니다. 계정 정보는 사용자 본인의 기기에만 저장됩니다. 이 앱에서 차량을 등록하면 실제 단지의 출입통제 시스템에 반영됩니다.
