For residents of a building that uses iParking: register parking for visitors coming to your own home, through iParking MEMBERS. This is an unofficial, community-built app and is not affiliated with iParking.

You need your own unit's account at a building enrolled in iParking MEMBERS. One account belongs to one unit and can only register visitors coming to that unit, so sign in with your own credentials and register only vehicles visiting you. A registration takes effect on your building's real access-control system immediately — do not enter arbitrary plates to see what happens.

Sign in once in the app settings, and the device shows five values at a glance: how many vehicles are expected today, tomorrow and over the next seven days, how many are parked inside right now, and when the next visit is due. All five come from a single request. From the settings page — the app's main screen — pick a lot, enter a plate number and a visit date, and register a visitor; whitespace in the plate is stripped automatically. Review and cancel registrations from the same page, covering three months back and three months ahead, or register from a Flow action. Save frequent visitors as a name and plate to get a one-press button for each.

Re-registering an already-registered plate is reported as its own outcome rather than an error, and if a registration's result cannot be confirmed the app tells you to check the iParking website directly instead of guessing or retrying.

This is an unofficial client for an API iParking has never published, so the vendor can change it and break this app without notice. iParking's own API server redirects every secure request to a plain connection, so the access token and plate data travel unencrypted after sign-in — this is the vendor server's behavior and cannot be changed from this app. Sign-in itself uses a verified secure connection. Credentials are stored only on your own device and are sent nowhere but iParking's servers; the app performs no analytics and runs no server of its own. "Parked now" is read hourly, so it can be up to an hour behind.
